## 🪴 About

This is my personal portfolio website — a space where I showcase who I am, what I build, and what I'm learning. Designed with a clean, minimal aesthetic and built entirely with core web technologies.

---

## ✨ Features

- 🌱 Responsive design — looks great on mobile, tablet & desktop
- 🍃 Smooth, minimal UI with an emerald-inspired theme
- 📁 Project showcase section
- 📬 Easy-to-find contact / social links
- ⚡ Fast load times, lightweight codebase

## 🚀 Getting Started

Want to run this locally? Here's how:

```bash
# Clone the repository
git clone https://github.com/Saniya0301/saniya-portfolio.git

# Navigate into the project
cd saniya-portfolio

# Open index.html in your browser
```

No build tools or dependencies required — just open and go. 🌿
